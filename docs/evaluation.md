
# Evaluation

The platform includes an LLM-as-a-Judge evaluation harness that can score any workflow run. Four scorers: faithfulness, relevance, completeness, citation accuracy.

Filled out fully in Phase 10. The structure: scorer definitions, the golden set format, the scorecard output, the side-by-side comparison flow (workflow version A vs B, prompt version A vs B), and the eval history view.
